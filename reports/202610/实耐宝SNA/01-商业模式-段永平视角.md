# 实耐宝 Snap-on (SNA) 四大师报告 · 段永平视角
## 01 商业模式 —— 这是不是一门好生意？

> **口径声明**：全部数据引自《00-数据包.md》（2026-10-16），未引入外部数据，未重算任何比率。
> **视角声明**：我看公司就三条——生意模式好不好、人对不对、价格便不便宜。这篇讲前两条加打分，价格的事留给巴菲特那篇去磨叽。

---

## 一、生意本质：一句话

**Snap-on 就是：一队每周开进修理厂后门的移动柜台（van），把专业级工具（多数还是赊账）卖给技师，靠品牌让技师心甘情愿多付钱、靠封闭渠道让加盟商稳定赚钱的「收费站」生意——车流，就是全美技师的钱包。**

说人话：它不是卖工具的，它是收「技师工具税」的。收税的人，生意不会太差。

## 三、核心判断 a）：van channel 是不是「下游愿意持续付钱的封闭生态」？

**结论：是，教科书级的。看两件事就够了。**

**1. 下游付了钱，是不是多赚钱了？**
- 加盟商（franchisee）不是 SNA 的员工，是拿自己真金白银进货的小老板。他年年进货、年年续——FS 应收款组合「稳定」（Q2'26 原话），FS 一个季度就赚 $67.5M 营业利润。**数据包没直接给加盟商资产回报率，但 $1.9B 应收款没烂账迹象、加盟网络还在低个位数扩张，这就是加盟商在赚钱的最诚实证据——他们用真金白银投票，比任何调研都准。**
- 技师端更硬：美国汽修技师空缺 ~92,000 个（1/8 工位没人），车龄 12.8 年历史新高。在岗技师更值钱、活更多，好工具直接变成他个人的接活量和收入。**技师买 SNA 不是消费，是给自己加杠杆——这是全行业最健康的客户结构。**

**2. 能不能绕开？**
- 绕开的成本 = 时间 + 信用 + 风险：van 周周开到修理厂后门，技师一分钟都不用花在逛店上；诊断、正时、EV 高压这些专业级独供品类，大卖场货架上没有；没钱？FS 直接赊给你（金融业务是利润引擎，数据包原话）。
- 这个渠道模式跑了 100 年没人复制成功——不是别人想不到，是**又苦又慢、资本不爱干。资本不爱干的苦生意，恰恰是最结实的护城河。**

一句话：**客户持续付钱，是因为付了钱他自己更赚钱；绕不开，是因为绕开的代价比省下的钱大。两条都满足，就是封闭生态。**

## 四、van 封闭生态 vs TTI 分销模式对比（数据包 §5）

| 维度 | SNA van channel | TTI 分销模式 |
|---|---|---|
| 渠道 | 自有移动门店（van）直达修理厂 | Home Depot/Amazon/承包商分销，直供大承包商 |
| 客户 | 汽修技师个人（专业级） | 承包商 / DIY / 电商消费者 |
| 营收 | $5,275M，+4.0% | $15,718M（SNA 的 3 倍），+3.0% |
| 营业利润率 | **25.2%（全行业最高）** | 9.1% |
| 净利率 | **19.6%** | 8.3% |
| ROE / ROIC | 17.9% / 18.4% | 18.6% / 19.1% |
| FCF Yield | 5.82% | 6.40% |
| PE | 18.7x（现金牛定价） | 23.4x（增长期权溢价） |
| 渠道重叠 | **不直接重叠**（数据包原文），但终端钱包份额竞争在技师/承包商个人支出上 | 同左 |

**段式注解**：TTI 是「把货铺满世界」，SNA 是「把柜台开到客户后门」。前者赚辛苦钱，后者收生态钱——SNA 的利润率是 TTI 的近 3 倍，钱赚得舒服得多。但别飘：TTI 的 ROIC 19.1% 不输 SNA，Milwaukee 靠走量活得很好，AI/数据中心工具线还在重估（TTI 2026 年市值 +49%）。**两种模式都能赚钱，最危险的姿态是高估收租的自己、小看走量的对手。**

## 五、核心判断 c）：Milwaukee 侵蚀下，品牌定价权还成立吗？

**成立，但有边界。**

- 证据：25.2% 营业利润率 vs TTI 9.1%；Q2'26 毛利率 51.4%（还 +90bp）；Q2'26 是创纪录季度，Snap-on Tools Group 营收 +3.6%、van 低个位数增长。**如果 Milwaukee 真把技师钱包抢穿了，这些数字不可能同时成立。**
- 但别装看不见：Tools Group 营业利润率 22.6%，**同比 −120bp**（毛利率 −30bp 产品组合 + opex +90bp 人员运费投入）——侵蚀不在总量上，在边际上。
- 我的判断：SNA 守得住的阵地是技师绕不开的专业级品类（诊断/正时/EV 高压/航空军工）；Milwaukee 抢得走的是电动工具、技师 discretionary 的那一块钱包。
- **护城河没有塌，但河边有人挖土。** 盯住两个数：Tools Group 利润率、van 增速。这两个数一坏，故事就变了。

---

## 六、核心判断 b）：KKR 持股 13%，管理层与股东还一致吗？

- 事实（数据包 §7）：2017 年 $500M 可转换优先股已转普通股，~13%，第二大股东，**无投票权特殊安排**，「存在存在感」。
- 我的看法：**13% 是个不上不下的数。** 好处：财务投资者的钱不白投，会盯着管理层别乱来（乱并购、乱扩张）——外部纪律免费送。坏处：KKR 终究要退出的，它不是 Pinchuk 的老板，也不是技师的朋友，到了退出窗口，动机会和长期股东错位。
- 结论：**KKR 在，不加分也不减大分。真正的衡量标准是资本配置记录——股息 16 年连增、稳定回购、并购只做小额补强（Hi-Force/Diesel Laptops 本季才贡献 $11.5M），净债务才 0.7x EBITDA。记录清白，先信记录。**

## 七、Pinchuk 是不是「对的人」？

**是，但这份答卷快交卷了。**

- **对的地方**：18 年把一家工具公司做成了利润率机器——净利率五年 +6.5pct，ROE 18.2% 的提升全由利润率驱动，周转和杠杆都没动，这是「把事情做对」的硬证据。RCI（Rapid Continuous Improvement）不是墙上口号，是每周都在跑的机器。
- **扣分项**：68+ 岁，**无明确接班计划披露**（数据包跟踪点）。一个组织靠一个人，就不是好组织。这门生意本身结实，接班人平庸坏不了它；但要是来个「把事情做错」的新老板，25% 的利润率是头一个被动的数。
- 关税立场（美国本土制造、净受益/中性偏正）说明管理层会借势——但这类顺风不本质，不多给分。

## 八、核心判断 d）：成长性，严格打分

| 指标 | 数字 | 判词 |
|---|---|---|
| 营收 CAGR 23-25 | **3.55%** | 低个位数，平庸 |
| EPS CAGR 23-25 | **0.43%** | 几乎零增长（2025 EPS −3.3% 含 Fair Value 损失，2026 修复中：Q1'26 +20%、Q2'26 +5.1%） |
| 营收 CAGR 20-25 | 5.86% | 五年尚可，近三年明显降速 |
| Q2'26 有机增速 | +3.0% | 中性 |
| 顺风 | 技师缺口 ~92,000、车龄 12.8 年 | 结构性顺风，但撑不起高增长 |
| 隐忧 | 技师总数长期下降、EV 蚕食 ICE 工具类目 | 客户基数的天花板 |

**打 2.75，不含糊。** 买 SNA 不能当成长股买，要当「确定性极高的印钞机 + 温和通胀传导」买。它**涨价的能力（毛利率 51.3%）大于它长大的能力（3.55%）**——这种生意慢，但睡得着觉。

## 九、段式结论

- 这是一门**本分生意**：不追风口（不上大卖场、不烧钱打电商），守着 van 渠道一百年；新品类敢为天下后——电动工具、诊断、EV 工具跟在别人后面做，后中靠技师关系争先。Stop doing list 清晰：不碰 DIY 大众市场、不做大并购、不加杠杆。
- **商业模式一流，成长性二流，价格中性。** 概率加权 IV $370 vs 现价 +0.2%，市场把这门生意定价得分毫不差——好公司不等于好股票，中间差的就是那个价格。
- 护城河还在，但要记住：河边有人挖土（Milwaukee）、客户基数有天花板（技师总数）、老板快退休了（无接班计划）。这三件事没一件是当下的麻烦，但每件都值得每年查一遍。
