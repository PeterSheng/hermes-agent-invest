## 3. 共识与分歧

### 3.1 强共识（四位大师独立得出）
1. **生意质量接近满分**：FAA-PMA 认证壁垒 + 单一来源专有件 + 价值（而非成本）定价 + 装机锁定 20-40 年备件流；有形 ROIC 79.7% 是全系列最高纪录
2. **并购是真功夫而非市值管理**：含商誉 ROIC 15.6% > WACC 9%——收购溢价的回报覆盖资本成本（与赛默飞 8%≈WACC 的"买增长不赚钱"有本质区别，这也是 TDG 商业模式分高于赛默飞的原因）
3. **价格零安全边际**：DCF 概率加权 $809（-26%）、敏感性 20 格全部 < $1,100、FCF Yield 3.17% < 美债 ~4.5%、现价隐含 g1 = 11.9% 永续
4. **organic 后市场降档是核心经营风险**：Q4FY25 miss（单日 -10.4%）+ commercial aftermarket 从 20%+ 降至 ~10-12%，市场已用 -25% 回调定价了一次

### 3.2 唯一实质分歧：杠杆的定性
| 大师 | 杠杆定性 | 权重 |
|---|---|---|
| 段永平 | 钝痛型非崩盘型——商业模式内嵌杠杆，扣分不一票否决 | 中 |
| 巴菲特 | 赌桌——6 倍净杠杆+负权益+2.41x 利息覆盖 = 回避级（TCO/卡夫教训） | 重 |
| 芒格 | 概率化：信用悬崖仅 ~6%（FCF $1.9-2.4B 全是付息后现金，EBITDA 需跌 30-35% 才触发），但利率 +150bp 侵蚀 FCF 15-18% 是基准情景 | 重 |
| 李录 | 复利质量折扣：vs Heico（同模式、杠杆 <1x、ROE 20%+）——TDG 的杠杆让长期复利从"机器"降档为"走钢丝的机器" | 中 |

裁决采纳芒格的概率化框架作为调和：**杠杆不是否决项（崩盘概率低），但是估值折价项（FCF 的 15-18% 对利率敏感、股权在资本结构最末端）**——这正是李录硬规则把 3.50 封顶到 3.25、巴菲特压到 2.50 的同一逻辑的不同表述。

## 6. Follow-up：直击痛点的核心问题

**FY2026 Q4 财报（约 2026-11 上旬）必须回答一件事：9 月新发的 ~$5.5B 债务（报道口径）的实际票面成本是多少？** 这是当前估值链上最脆弱的一环——若新债成本 > 6.5%（高于 6.1% 的存量平均利率），利息覆盖将从 2.41x 进一步滑向 ~2.2x，芒格的"利率 +150bp 侵蚀 FCF 15-18%"就从情景推演变成既成事实，DCF 中性情景的 $777 将失去支撑；反之若公司以 ≤6% 锁定长期资金，则证明债权人仍在补贴这座收费桥，"钝痛"叙事成立的概率大增。**这一张票据的定价，比任何一季 EPS 都更能区分 TDG 是"借来的收费站"还是"收费的印钞机"。**
