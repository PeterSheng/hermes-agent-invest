## 一、一句话结论

这是一对**用"关联交易"名义披露、但真实依赖度被系统性低估的母子平台**：港交所 14A 章口径下，滨江服务来自滨江房产集团体系的关联交易收入只占 **7.5%**（2025）；但把"项目来源"还原进去——业主端物管费、家装费——**滨江体系实际决定了滨江服务约 62% 的收入、约 70% 的毛利**。而**车位销售**是这套关系里最特殊的一环：它不是收入，而是**滨江服务用现金向母公司买存货**，2025 年付出 7,900 万元、2026 上半年骤降至 1,278 万元，同时存货连续两年计提减值，撇减率从 0% → 4.8% → 9.2%。

**三点治理含义：**
1. **滨江服务不是滨江集团的子公司**（无股权嵌套），因此滨江集团**不并表**滨江服务、**不直接收取**滨江服务分红（分红流向三个家族信托）——这削弱了"母公司抽血"的最直接通道，但要记住这三个信托的受益人就是滨江集团的实控人。
2. 滨江服务的**董事会主席不是戚金興**（余忠祥为职业经理人），比华润万象生活（董事长李欣同时主持两家董事会）的治理格局**显著更好**；但戚加奇、莫建華同时在滨江服务董事会，且在滨江集团侧作为关联董事回避表决。
3. **关联交易的"独立审议"在董事会层被实质削弱**：莫建華既是滨江集团总经理/法定代表人（滨江控股总经理），又是滨江服务非执行董事、ESG及策略委员会主席——他同时出现在两边的关联方名单上。

### 3.2 交易的法律定性

- 滨江房产（002244）是滨江服务的**关连人士**（受同一控股股东控制的公司）→ 全部交易适用上市规则**第14A章**。
- 2026年四份协议（物业管/销售代理/顾问/车位购买）的适用百分比率**>0.1% 但全部 <5%** → 只需**申报+公告+年度审阅**，**豁免独立股东批准**（Rule 14A.76(2)）。
- **例外**：2025年交付前管理服务主协议一项或多项目比率**>5%** 且总代价 >1,000 万港元 → 必须**通函+独立股东批准**，已于 **2025-01-17 股东特别大会通过**。

## 五、专项：车位销售（"优家服务"下的停车位/储藏室业务）

### 5.1 交易结构：不是"卖车位给母公司"，而是"向母公司买存货再零售"

| 环节 | 具体安排 |
|---|---|
| **协议名称** | 《停车位、储藏室及商铺购买主协议》（2025年协议2024-12-05签署，2026年协议2025-12-17签署重续） |
| **方向** | **滨江服务向滨江房产集团付款购买**（"取得由滨江房产集团开发拥有并由本集团管理项目内的停车位、储藏室及商铺作为再销售之用途"） |
| **标的权利** | 停车位、储藏室取得**使用权（含占有及转让权）**；商铺取得**产权** |
| **定价机制** | ①每一个交易项目须由**符合资格的独立第三方资产评估师出具估值报告**；②**购买价格（对价）不得超过该评估价**；③任何情况下不得逊于邻近同定位项目的现行市价；④估值已考虑"是否完成时全额支付"及"批量购买折扣" |
| **付款安排** | 完成时全额支付（估值因素之一） |
| **会计处理** | 购入计入**存货—持作转售的物业**（使用权资产）；转售给业主时确认收入，列于 **5S增值服务—优家服务**（含车位及储藏室服务） |
| **收入体量** | 优家服务（含一手/二手经纪、租赁代理、车位及储藏室服务）2025 年收入 **1.01 亿元**（占收入 2.5%，同比-2.7%）；2026H1 **0.63 亿元**（+31.5%） |
| **为何出售方愿意卖** | 公告原文："项目开发完成后，滨江房产集团的项目销售部门搬出项目所在地，本集团作为相关项目业主的物业管理服务提供商，更**方便接管批量销售期后剩余停车位、储藏室和商铺的转让**"——**本质是母公司批量销售期结束后，把"剩货"打包给子公司消化，母公司提前回笼现金** |

### 5.3 存货与减值：买方在承担价格风险

| 时点 | 持作转售物业（千元） | 存货撇减（千元） | 撇减率 |
|---|---:|---:|:--:|
| 2024-12-31 | 289,558 | **0** | 0% |
| 2025-12-31 | 349,208 | 16,740 | **4.8%** |
| 2026-06-30 | 335,523 | 30,839 | **9.2%** |

**读法（重要）：**
1. 交易机制设计上，滨江服务"**价格不超过独立评估价**"——听起来无懈可击。但**2025 年首次出现减值、2026H1 撇减率翻倍**，说明**评估价与实际可变现价值存在系统性正偏差**：评估师按"当前市价+批量折扣"给出上限价，而真实去化需要打折。
2. **存货绝对额（3.36 亿）远高于年采购量（0.79 亿）**：约等于 3–4 年的采购量或 5 年以上的转售量（优家服务年收入仅 1.0 亿且含经纪/租赁）。**资金被长期锁在"母公司剩货"里**。
3. 2026H1 **净增**撇减 1,410 万元 ≈ 当期归母净利（3.15 亿）的 **4.5%**；期末撇减余额 3,084 万元 ≈ 半年净利的 **9.8%**。这也是当期毛利率从 22.5% 掉到 20.8% 的原因之一。
4. **谁得到什么**：滨江集团获得**即期现金回笼**（完成时全额支付）与**报表去库存**；滨江服务承担**存货、资金占用与减值**。这在行业下行期是**对母公司有利、对子公司不利**的结构——与华润万象生活"分租模式把空置风险转给子公司"是同一类问题。
5. **对冲视角**：2026 年采购骤降 66.7%（上限 1.5 亿仅用 8.5%），可以正面解读为**滨江服务主动收手、不再为母公司去库存买单**——这是本次分析中最重要的正面信号。

## 六、依赖度量化：双口径交叉验证

框架要求：**不用单一口径下结论**。数量口径与金额口径若吻合，依赖度即可采信。

| 口径 | FY2025 | 2025H1 | 2026H1 |
|---|:--:|:--:|:--:|
| **数量口径**（滨江集团开发物业在管面积 ÷ 总在管面积） | 35,932/82,629 = **43.5%** | 33,416/75,083 = 44.5% | 39,949/92,677 = **43.1%** |
| **金额口径**（滨江集团开发物业物管收入 ÷ 物管总收入） | 1,224,789/2,441,326 = **50.2%** | 582,325/1,158,370 = 50.3% | 694,207/1,399,901 = **49.6%** |
| **项目数口径** | 222/518 = 42.9% | 201/470 = 42.8% | 244/577 = 42.3% |

**结论：两个独立口径吻合在 6.5 个百分点内（面积 43% vs 金额 50%）**——金额口径高于面积口径，说明**滨江集团开发项目的物管费单价高于第三方项目**（高端定位）。依赖度可采信为**"约四成面积、约五成物管收入"**。

**趋势判断（关键）：依赖度并未下降。** 2025H1 → 2026H1，面积口径 44.5% → 43.1%（-1.4pct）、金额口径 50.3% → 49.6%（-0.7pct）。滨江服务喊了多年"外拓第三方"，但**第三方在管面积增速（+26.6%）只比母公司快 8pct，占比几乎没动**。

⚠️ **一个被忽略的领先指标**：滨江集团开发物业的**"前期阶段"（开发商阶段）面积从 16,122 → 15,280 千㎡（-5.2%）、收入 2.82 亿 → 2.60 亿（-7.7%）**，而"业委会阶段"（存量留存）面积 +42.6%。含义很清楚：**存量项目在沉淀（好事，粘性），但新交付管道在收缩（坏事，成长性）**。

### 12.2 值得记下来的三句估值语言

1. **"9 倍 PE 的公司，72% 的市值是净现金。"** 市场给滨江服务的定价隐含：**这家公司赚的钱里，只有约 1/4 被认为属于中小股东**——这就是关联交易折价的量化形态。
2. **"折价的对象应该换一换。"** 若把 62% 的收入依赖计入，则滨江服务的合理折价不是给"物管生意"，而是给"**管道租金**"——**折价应挂在利润，而不是挂在收入**（毛利依赖 70% > 收入依赖 62%）。
3. **"9% 股息率与 72% 净现金，是市场对同一件事的两个报价。"** 股息率之所以高，是因为**分红的来源（利润）被怀疑**；净现金之所以占比高，是因为**市场不愿为业务付钱**。两者同时存在，正是"看不清"状态的标准形态。

|---|---|---|
| 市值 | HK$58.05 亿 | ¥249.54 亿 |
| PE(TTM) | 8.8x | 13.75x |
| PB | 2.9–3.2x | **0.81x** |
| 2026H1 净利 | ¥3.15 亿（+5.8%） | ¥15.5 亿（-16.3%） |
| 关键资产 | 净现金 ¥38.5 亿 | 存货 ¥958 亿 + 预收房款 ¥736 亿 |

**同一实控人体系下的两个上市平台，被市场给出"3x PB 的轻资产服务商 vs 0.81x PB 的重资产开发商"的定价**——这与华润案例（万象生活 5.2x vs 置地 0.49x）同构，但**滨江服务的高 PB 建立在 37% 的 ROE 上，而该 ROE 有相当部分是关联交易和预收款浮存的产物**。

## 十三、投资者三问

1. **段永平式——"这门生意是不是我的？"**
   不是。你的股权是 28.37% 的公众持股，而**收入的 62%、毛利的 70% 由一个不由你控制、也不由滨江服务控制的开发管道决定**。车位业务更极端：那是**别人的库存管理问题，被搬到你的资产负债表上**。

2. **巴菲特式——"利润率是不是我的？"**
   部分不是。5S 增值服务（含家装 9.9 亿、车位转售）毛利率 28.5%，**定价基础来自"滨江房产开发的高端项目＋品牌光环＋免费商标使用"**。把商标费按市场价补记、把车位存货按真实可变现价重估（现撇减率 9.2%），毛利率会低多少？**这是可以直接算的、却从没人算的账。**

3. **芒格式——"我最怕什么？"**
   不是怕滨江集团出事（它净负债率 -0.76%，比多数央企开发商还干净）。**要怕的是母公司"体面地缩小"**：
   - 交付量下滑 → 交付前服务（2026H1 却 +38.8%）**先冲高后失速**，因为它是**放大器**；
   - 商业公寓去化放慢 → 家装（-6.2%）**逐季缩水**，合约负债已从 13.55 亿降至 10.01 亿；
   - 剩货增多 → **车位采购上限再次被用起来的诱惑**（2026H1 只用了 8.5%），而这正是最可能发生价值转移的通道；
   - 而**这三件事都只需要一个理由**："集团整体利益"。

## 十四、AlphaFind 终极一问

> **如果滨江服务账上的 3.36 亿元"待售停车位与储藏室"被要求在 12 个月内清零（而不是以 9.2% 的撇减率慢慢持有），那么这些资产真实的可变现价值是多少——而这个差额，究竟该记在滨江服务的损益表上，还是应该被理解为滨江服务过去三年为母公司"剩货"支付的、一笔从未被披露的隐性服务费？**

这个问题的争议性在于：**如果答案是"差额不大"，则 8.8 倍 PE＋72% 净现金的滨江服务是本轮物管股中被错杀最深的标的之一；如果答案是"差额很大"，则它的高 ROE 有相当部分并非经营能力，而是尚未兑现的存货损失。**——而市场现在同时给出了 9% 股息率和 72% 净现金占比，说明**它还无法回答这个问题**。
