# 03-风险分析·芒格视角 —— 潍柴动力（000338.SZ / 2338.HK）

**分析基准日：2026-09-25 | A股 ¥26.91 / H股 HK$29.00 | 总市值 ~2319亿元**
**方法论声明：本文只回答一个问题——"潍柴怎么会死"。所有估值数字直接引用数据包第六节，不重算、不引入外部数据。**

## 一、逆向问题开篇：如果潍柴动力10年内会崩盘，怎么崩？

芒格的规矩：告诉我会死在哪里，我就永远不去那里。

把2026-09-25的潍柴摊在桌上：一份表观归母+36.46%的中报，拆开一半是一次性损益（巴拉德减持13.27亿），扣非只+18.86%；一个收入+14.9%而利润-2.1%的发动机分部，公司没有解释；一个市场按"FCF腰斩"定的价——现价反推隐含可持续FCF约101亿，只有3年实际均值203亿的一半。

市场已经开始怀疑，管理层还没给答案。这种公司的崩盘剧本不需要想象力，只需要把已有的裂缝画到底。崩盘不是单一事件，是六条路径的接力。

## 二、六条可信失败路径

*⑤为10年渐进侵蚀的累计冲击，非一次性事件。

**逐条展开：**

**① 重卡二次探底（30% / -35%）**——先例就写在历史里：2020年162万辆→2022年67万辆，腰斩只用两年；2022年公司归母49.05亿(-47%)、净利率2.8%、OCF -23.5亿、FCF -90亿。2026年确实在复苏（1-8月71.57万辆+14.5%，全年预计约110万辆），但请注意：复苏中的行业销量也只有2020年峰值的2/3。周期股的"复苏确认"从来是后视镜里的景象。

**② AIDC叙事破灭（30% / -22%）**——2026H1大缸径1400+台已超2025全年总量（2025年约1400台、+259%），高基数之后的增速悬崖是数学问题，不是观点问题。竞争端康明斯/卡特彼勒/MTU全线扩产，国内科泰电源、济柴贴身缠斗；结构端更致命——高盛都提示燃气轮机和SOFC作为现场主用电源的重要性在提升，柴发备电的饭碗可能被端走。**第一个裂缝已经出现：发动机分部业绩率17.11%→14.57%（-2.54pct），收入+14.9%而分部业绩-2.1%，公司未解释。**故事最性感的地方恰恰是利润最先失血的地方，这不是巧合。

**③ KION商誉减值（20% / -15%）**——商誉242.8亿，占归母权益25.3%，五年稳定在240-253亿。稳定不等于安全，只等于还没爆。凯傲2025年效率计划已计提12.76亿（影响归母3.93亿，直接把当年归母打成-4.1%）；2026H1 KION净利15.34亿也只是回到2024H1（14.26亿）的水平，谈不上修复完成。欧洲工业疲软是持续的背景噪音。

**④ 关税地缘（40% / -10%）**——国外收入629.96亿占51.15%，国外毛利率24.36%→22.16%（-2.2pct）已经在掉。概率最高、单发冲击最轻，属于慢性失血型风险：不会崩盘，但会一年偷走你一个点的利润率。

**⑤ 新能源替代（70% / -12%，10年摊）**——2026年5月新能源重卡3.08万辆（+104%、4连增），从封闭场景向干线物流延伸。这不是周期，是趋势；10年内柴油动力见顶接近确定性事件。潍柴约30%市占率的柴油发动机是现金牛，现金牛的宿命是被新技术放血。对冲项存在：新能源电池4.7GWh（+103%）、2026Q1新能源收入16.9亿（+200%）、SOFC与Ceres合作——但"自己革自己的命"这门手艺，历史上真正掌握的公司屈指可数。

**⑥ 战略漂移（35% / -10%）**——谭旭光2025-08-12因年龄辞任，执掌20余年。遗产有三条：心无旁骛攻主业、研发投入做到96亿/年、上市20年分红超300亿的资本纪律。接班人马常海2023年就进了董事会，平稳是设计出来的，不是验证出来的。早期漂移信号已现：研发占营收3.73%（两年前4.25%），资本化率10%→13.3%——钱还在花，但美化的手已经伸出去了。大企业接班后的腐烂从不始于贪腐，始于温和的美化。

## 四、芒格最担心的两个核心问题

**问题一：AIDC高增长能否穿越周期，以及那个增收不增利的黑箱里装着什么？**

发动机分部收入373.10亿（+14.9%），分部业绩54.37亿（-2.1%），业绩率17.11%→14.57%，掉了2.54个百分点，公司没解释。数据包里"可能因素：产品结构/出口结构/燃气机占比"是猜测，不是管理层的回答。再叠加表观与真实的落差——归母+36.46%里巴拉德减持贡献13.27亿一次性损益，扣非+18.86%才是真增速。当一家公司最性感的增长故事（1400台、+259%、订单排至数月后）和最不体面的利润表现出现在同一个分部，而你不知道为什么——芒格的规矩：看不懂的黑箱，要么拆开，要么别付钱。¥26.91对应TTM PE 17.9x、扣非21.8x，黑箱没拆开之前，这个价格买的不是确定性。
验证路标：2026年报发动机分部业绩率；2027H1大缸径销量增速是否兑现公司"今年和明年仍将维持高速增长"的原话。

**问题二：灵魂人物走后，资本配置纪律还能撑几年？**

谭旭光的潍柴有三条铁律：不分心、不乱花、不抠门。退休后的第一份中报出现两处松动：研发占营收3.73%（两年前4.25%）、资本化率10%→13.3%。不是控诉，是路标。正面证据同样存在：中期分红44.67亿=H1归母58%（2025中期55%），分红率还在升；净现金450亿没被惦记着去搞多元化。观察期三年，盯三个指标就够：研发/营收比、资本化率、分红率。三者同时恶化之日，就是⑥路径概率上调之时。

## 五、"反过来想"：什么条件下潍柴是安全的好价格？

先数下行保护——芒格唯一关心的那种"安全"：
- **净现金450亿**（货币资金775.4亿 vs 有息负债325.2亿），约当市值的两成；剔净现金PE 14.4x
- **FCF Yield 8.8%**（归一化FCF 203亿，P/FCF 11.4x）；即使盈利腰斩到市场隐含的101亿，现价对应的Yield仍在4%量级
- **股息约3.2%**，中期分红44.67亿=H1归母58%；2022年周期谷底OCF做到-23.5亿，公司照样活到复苏——这就是净现金的意义
- **悲观DCF IV ¥20.9 = -22%**：这是市场把"重卡再探底+AIDC不算数"全部计价后的价格。换句话说，最坏的剧本也只要求再跌22%，而中性剧本（¥35.3，+31%）和乐观剧本（¥61.9，+130%）在场外等着

安全的好价格成立的五个条件：
1. 扣非增速维持双位数（2026H1的+18.86%是底线样本），一次性损益占比不再扩大
2. 发动机分部业绩率止跌回17%一线，或管理层给出可信解释
3. 大缸径销量2026-2027不出现增速悬崖
4. KION净利不再恶化，242.8亿商誉无新增计提
5. 分红率≥55%、研发占比止跌

五条满足，¥26.91下方皆为"安全的好价格"；若股价向悲观IV ¥20.9靠拢，则是"用悲观价买中性概率"的击球区。提醒一句：AH比价0.989，H股罕见地没有折价安全垫——两个市场一样贵，也一样便宜。

## 六、芒格式结论 + 投资吸引力评分

潍柴不是会一夜暴毙的公司：净现金450亿、FCF Yield 8.8%、股息约3.2%，下行有垫子。它的问题是，你付的每一块钱里混着三样东西——看得懂的重卡周期修复、看不懂的发动机利润率黑箱、以及市场拒绝定价的AIDC叙事。市场按"FCF腰斩"定价说明它不傻；管理层不解释业绩率下滑，说明你也不该太傻。六条路径概率加权约-3%/年的长期侵蚀，需要8.8%的FCF Yield与+31%的中性上行来覆盖——覆盖得住，但不宽裕。**这是击球区边缘的球，不是站在击球区中心等全垒打：可以挥棒，仓位说话。**
