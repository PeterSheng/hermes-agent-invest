# 01｜商业模式 · 段永平视角

**华润万象生活（01209.HK）｜高端商业运营绝对龙头（商管+物管）｜分析日：2026-09-03**

> 段永平框架五问：这生意看得懂吗？商业模式好不好？护城河深不深？管理层是不是"对的人"？这个价格买划算吗？

## 0. 一句话概览

华润置地孵化的高端购物中心"商管+物管"龙头。**用别人的地、别人的钱，靠"万象"招牌赚管理费与租金分成**——轻资产、高毛利、高分红、几乎无应收账款。2026H1 在社消零售总额仅 +1.4% 的逆风下，毛利率逆势升至 38.0%、核心净利 +10.8%，再次验证"高端消费向头部集中"的结构性逻辑未破；代价是增速从 2025H1 的 +15% 换挡至 +10.8%，写字楼与增值服务开始拖后腿。**好生意，在换挡，价格合理但不便宜。**

## 2. 生意本质：一句话定义

> **一门有央企信用背书的"高端收租+收管理费"生意：母公司华润置地出钱盖商场、收业主端租金，万象生活出品牌与运营、按面积与业绩收服务费——上市公司赚的是旱涝相对保收的"管理费"，而不是重资产租金本身。**

三个关键推论：
1. **利润质量高于收租本身**：纯服务费收入、无投资物业重估波动、现金流干净，五年净利率从19.4%升至22.0%；
2. **天花板受制于人**：母公司输送+第三方外拓两条腿缺一不可——储备72座中第三方40座已超母公司32座，轻资产外拓正式接棒；
3. **赚"确定的慢钱"**：不碰重资产，也就放弃了租金上涨的大弹性——这是模式选择，也构成估值上限。

## 3. 护城河：四层拆解

### 第一层｜品牌：高端商业的"爱马仕选址风向标"
- 爱马仕中国17家门店中 **6家开在华润系商场（约35%）**——奢侈品牌用脚投票，比任何广告都有力；
- 2025年重奢项目零售额 +18.5%（可比 +15.3%），跑赢行业两位数；
- 在营135座中 **54座当地销售额第一、105座当地前三**：万象城=城市商业名片。

### 第二层｜规模：全国网络的正循环
- 2025年零售额 **2,660亿（+23.7%，可比 +12.2%）**；业主端租金307亿、NOI 201亿、**NOI Margin 65.7%**——业主赚到钱，才愿意持续把项目交给万象管；
- 截至2026-06-30：在营购物中心138座（管理输出模式132座+利润分成3座+整租3座）、商业运营写字楼30座、物管在管面积4.41亿㎡；2025年新开14座、新签第三方12个；
- 网络越密→品牌与租户资源越强→新项目爬坡越快——第三方业主主动上门的飞轮。

### 第三层｜母公司：央企信用+项目输送
- 储备未开72座中 **32座来自华润置地**，"十五五"城市布局直接转化为上市公司确定性增量；
- 央企信用背书：融资成本、招商谈判、地方政府合作全面受益；
- 账面净现金约75亿元（≈市值9%），资产负债表干净到"无聊"。

### 第四层｜运营能力：把同样的mall管出更高的价
- 商业航道毛利率约63%，其中购物中心板块75.9%、运营部分高达82%；物业航道仅15–25%——利润引擎是"管"出来的；
- 多产品线分层收割：万象城（重奢）/ 万象天地（潮流）/ 万象汇（中产家庭），一套体系吃下不同能级城市；
- 可比零售额 +12.2% vs 社消零 +1.4%：**近9个百分点的超额，就是运营能力的定价。**

## 4. 管理层：是"对的人"吗？

**结论：基本是，但有两个段永平式追问放不下。**

✅ 对的地方：
- **说到做到**：连续第四年100%分派——2026H1中期股息0.586元+特别中期0.391元=0.977元/股，全额兑现承诺。"本分"二字在港股红利资产稀缺的年代尤其值钱；
- **不冒进**：轻资产扩张为主，不拿股东的钱赌重资产周期；写字楼出租率77.2%下行，也不靠补贴冲规模；
- **指引诚实**：2026全年净利指引约+11%，低于历史CAGR 23%——先降预期再超预期，是留给股东的安全垫。

⚠️ 追问两点：
1. **2024年133%超派（含特别股息）**：是"股东友好"，还是央企市值考核下对控股股东华润置地的资金归集？分派动机要打折扣看；
2. **激励平淡**：央企薪酬体系下，管理层与股东利益绑定弱于民企——好在"不求有功、但求无过"的稳健风格，恰好适配这门确定性生意。

## 5. 段永平式结论：中报验证了什么？价格合适吗？

### 5.1 中报验证：生意的韧性是真的

| 指标（2026H1） | 数值 | 点评 |
|---|---|---|
| 收入 | 92.17亿（+8.1%） | 物业航道+3.4%拖累，符合"底仓"定位 |
| 商业航道 | 36.99亿（+13.2%） | 主引擎，占比约40%且继续提升 |
| 毛利率 | 38.0%（+0.9pct） | 逆势提升=结构升级+经营杠杆，最难造假的一栏 |
| 核心净利 | 22.29亿（+10.8%） | 社消零仅+1.4%的背景下，含金量高 |
| 生态圈 | 1.88亿（+87.8%） | 新曲线，基数尚小，观察即可 |
| 股息 | 0.977元=核心净利100% | 连续第4年兑现，"言行一致" |

**一句话：最差的环境交出最好的结构——高端消费向头部集中没有结束，只是斜率放缓。** 下半年淮安万象城、杭州亚奥万象天地、苏州万象天地陆续开业，全年净利指引约+11%、同店零售额高单位数增长。

### 5.2 价格合适吗？——"好生意、合理价格"，不是"好价格"

| 估值坐标 | 数值 | 读数 |
|---|---|---|
| 股价 / 市值 | HK$40.56 / ¥849亿 | 中报后当日+3.89% |
| PE（TTM） | ~20.3x | 按指引+11%推算2026E约19x |
| PB / ROE | ~5.5x / 24% | 高ROE支撑高PB，匹配 |
| 股息率 | ~5.2%（派息率100%） | 类债券底仓，下行有托 |
| 净现金 | ~¥75亿（≈市值9%） | 估值含金量足 |
| 52周位置 | HK$36.14–50.17，现价约32%分位 | 中下部，不贵 |

段永平式算账：**持有回报 ≈ 股息率5% + 净利增长11% ≈ 16%/年**（估值不变时）；若未来零增长，20x PE的静态回报仅约5%——这门生意值钱就值在"高端消费集中度+轻资产外拓"仍有确定性的慢增长。券商目标价（中金61 / 大摩48 / 高盛52港元）普遍高于现价，但高盛已因写字楼租金预期下跌+增值服务放缓而下调2026–28盈利预测——机构也在为"换挡"重新定价。
**操作含义**：已持有者，拿着收5%股息即可，无需卖出；未持有者，20x PE谈不上占便宜——HK$36（52周低点）以下或18x PE附近分批，才是段永平会等的价格。

## 6. 投资吸引力总评分

# ★★★★☆ 4.25 / 5

**依据**：
- 商业模式（4.75）与品牌护城河（4.50）属顶级——这门生意段永平"看得懂"：收管理费、收分成、现金流干净，五年营收CAGR 19.4%、净利CAGR 23.2%由报表逐年验证；
- 管理层（4.00）本分但非卓越；成长性（3.75）确定性高但已换挡，宏观是唯一不可控变量；
- 四维平均 4.25。**价格因素暂不做加减**：20.3x PE + 5.2%股息属"优质永续资产的合理定价"，向上空间（机构目标价48–61港元）与向下保护（100%分派+净现金+央企信用）大致对称；
- **情景修正（段永平式最后一道闸）**：若回落至HK$36以下（≈18x PE），吸引力上调至 4.50★；若冲高至HK$48以上（≈24x PE），下调至 4.00★——好生意，也要有好价格。
