# 03 · 风险分析——芒格视角：信也科技（FinVolution，NYSE: FINV）

> **快照（2026-08-28）**：现价 $3.64 ｜ Q2'26财报后单日 **-9.45%**、52周新低 ｜ 市值 $859M ｜ PE **3.32x** ｜ PB **0.35x**
> TTM：净收入 ~RMB 105亿 ｜ TTM净利 ~RMB 18.5亿（≈$2.59亿）｜ 在贷余额 RMB 775亿 ｜ 促成贷款量 Q2'26 RMB 410亿（**-19.3%**）
> 现金+短期投资 RMB 64亿（8月末 ¥75亿）｜ 表内贷款 TTM RMB 95亿（FY23仅 ¥33亿）｜ OCF/NI 从 1.21 降至 **0.28**，Q2'26 OCF 为 **-RMB 3.9亿**
> 可转债：$150M、票息 2.5%、2030到期、转股价 **$12.36**（现价水下 71%）、**2028-07-03 持有人可回售 100%本金**

## 〇、反过来想：如果信也科技会崩盘，它怎么崩？

**3.32x PE、0.35x PB——芒格的第一反应永远是："市场知道什么我不知道的？"** 先列市场的恐惧清单，再问这些恐惧是幻觉还是远见：

| 市场的恐惧 | 证据（不是想象，是已发生的事实） |
|------|------|
| 怕监管把利润空间焊死 | 《个人贷款业务明示综合融资成本规定》8/1施行——息费透明化=定价上限显性化=助贷利润被直接压缩；3/13 金融监管总局已约谈五家平台 |
| 怕银行资金方撤退 | 促成贷款量 **-19.3%**——不是需求问题，是资金供给问题 |
| 怕逾期吃掉净资产 | Q1'26 行业 90+ 逾期率**全线 >3%**；FY24 质量保证承诺减值已高达 **¥45.9亿** |
| 怕现金是假的（出不来） | 坐拥 ¥73亿现金却发 $150M 可转债——**现金可支配性存疑的实锤** |
| 怕表内贷款变坏账 | 表内贷款从 ¥33亿 暴增至 ¥95亿——现金正在变成风险资产 |
| 怕历史包袱 | 前身是 P2P 拍拍贷（2019年转型），"日均700万利润与5万条投诉"的媒体质疑至今未散 |

**芒格的判断：这份恐惧清单不是恐慌，是精确。** 每一条都有白纸黑字的证据，且大部分是"正在发生"而非"可能发生"。市场给 3.32x PE 不是因为愚蠢，是因为**它看到了一个利润来源正在被监管关闭、资产负债表正在变重、而账面现金可能够不着**的公司。

## 二、现金可支配性风险专项（核心关切）

> **"账面现金"和"能花的现金"是两回事。芒格买烟蒂的第一条规则：现金必须拿得到手。拿不到手的现金，不是资产，是装饰品。**

**证据链①：受限金额超过账面现金。** 20-F 披露受限金额（实收资本 + 法定公积金 + VIE 净资产）合计 **¥93亿**——而账面现金+短期投资仅 **¥64-75亿**。境内子公司净资产中不可分配的部分，比全部账面现金还多。**换句话说：账面现金几乎全部对应受限净资产，可自由出境的部分微乎其微。**

**证据链②：2025-06 发可转债是"此地无银三百两"。** 公司在坐拥 ¥73亿现金时，仍发行 $150M 可转债（2.5%，2030到期）为**境外回购与分红**融资。芒格的反问：**如果现金真的能动，为什么要用 2.5% 的利息去借？** 答案只有一个——境外缺美元现金，境内的人民币出不来（WFOE 分红需 SAFE 审核 + 外汇管制）。

**证据链③：经营现金流正在枯竭。** OCF/NI 从 1.21 降至 0.28，Q2'26 OCF 为 **-RMB 3.9亿**。原因明确：表内贷款从 FY23 的 ¥33亿 增至 TTM **¥95亿**（已是全部现金的 1.5 倍）——**公司正在把流动性变成风险资产**，这是行业"重资产模式回归"的缩影。

**证据链④：分红可持续性推演（如果永远不涨）。** 假设维持 TTM 净利（~$2.59亿）50-60% 的派息率，年分红约 **$1.3-1.55亿**，对应 $8.59亿 市值股息率高达 **15-18%**。但现金来源三角：
- 经营现金流：TTM 仅约 $7,300万（OCF/NI 0.28），Q2 单季为负——**不够付一半股息**；
- 境内出境：¥93亿受限 + SAFE 审核，每年可出境额度有限且需审批；
- 境外存量：2025-06 发债时境外现金本就不足，否则无需融资。

**推演结论：以 $1.3-1.55亿/年的消耗速度，境外可动用现金 2-3 年内见底；2028 年可转债回售 $150M 再插一刀。届时要么砍分红（股息率叙事崩塌、股价再崩），要么指望外汇管制松绑（不可控）。** 市场给 15-18% 股息率，本身就是在定价"这个股息不可持续"——**这是市场的恐惧清单第四条，不是低估机会。**

## 三、行业性风险：这不是公司的问题，是行业的地基在动

**① 监管（最锋利）**：8/1 施行的息费透明化新规，攻击的不是某家公司的报表，而是**助贷商业模式的利润根源**——信息不对称 + 定价空间。金融监管总局 3/13 约谈五平台（分期乐/奇富借条/你我贷/宜享花/信用飞），信也未在列只是运气，不是豁免。**监管周期模型：P2P 清零 → 助贷野蛮生长 → 息费透明化整顿——钟摆正在摆向收紧，而信也的利润完全暴露在钟摆路径上。**

**② 资金方（最致命）**：助贷平台不拥有客户、不拥有资金，**两头都租**。银行收紧合作（促成量 -19.3% 已证实），平台连"规模"都没有了。**金融脆弱性模型（明斯基）：逾期率低的年份催生信用扩张，扩张积累脆弱性，脆弱性在逾期率 >3% 时集中兑现。** 行业正处在兑现期。

**③ 逾期（最慢但最毒）**：90+ 逾期率全线 >3% + 质量保证承诺减值 ¥45.9亿（FY24）——**激励错配模型**：助贷平台用"质量保证承诺"兜底，本质是把银行的信用风险买回自己表上；表内贷款扩张（¥33亿→¥95亿）则是把兜底从"表外或有"变成"表内实亏"。**鸵鸟效应**：投资者盯着 0.35x PB 和 15% 股息率，把脑袋埋进"便宜"的沙子里，无视资产负债表正在变重的事实。**便宜是最昂贵的幻觉——如果你买的是正在融化的资产。**

## 四、芒格最担心的两个核心问题

### 问题一：账面现金是真的吗？（价值投资的锚是不是假的？）

**整个"极度便宜"的叙事建立在现金和盈利之上。** 如果现金出不来（¥93亿受限 + 可转债融资实锤 + OCF 为负），那么 0.35x PB 买的就不是"5折的净资产"，而是"一堆出不了境的受限资产 + 正在扩张的表内风险资产"。**锚是假的，估值体系就全塌了。** 芒格会说：**我宁愿为一个能拿到手的 $1 付 $0.7，也不愿为一个看得见摸不着的 $1 付 $0.3——前者是投资，后者是彩票。**

### 问题二：这门生意的护城河是租来的，而且房东正在涨租。

助贷平台的三要素——客户（借款人）、资金（银行）、定价权（监管）——**没有一样在自己手里**。这不是护城河，这是租约；而房东（监管）刚刚把租金涨了一倍（息费透明化）。叠加 P2P 前身的历史包袱（5万条投诉的媒体质疑），**合规成本是结构性的、永久性的**。芒格对"租来的护城河"的态度一贯明确：**任何建立在他人善意（监管容忍、银行合作）之上的竞争优势，都不是竞争优势。**

## 六、芒格式结论：什么样的价格、什么条件，才值得买入？

**反过来想：不是"现在值不值得买"，而是"什么条件成立后，这个赌注才有正期望"。**

**买入必须同时满足的条件清单：**
1. **现金可支配性被验证**：连续 2 个季度 OCF 转正，且分红完全由经营现金流覆盖、无需发债——在此之前，账面现金一律按"受限资产"打折；
2. **表内扩张停止**：表内贷款不再增长，或明确收缩回助贷轻资产模式；
3. **逾期企稳**：行业 90+ 逾期率回落至 2% 以下，质量保证承诺减值环比收敛；
4. **监管定价明确**：新规细则落地后，take rate 可测算、利润可见——而不是"等靴子"；
5. **2028 回售有安排**：管理层明确披露可转债回售的现金准备。

**价格推演：** 若利润按失败路径①腰斩至 ~$1.2亿，按 5x PE（监管风险公司的合理上限）值 **$6亿**；若现金按 50% 可动用性打折（~$4.5亿）加清算视角，**$5-6亿（≈$2.1-2.5/股）以下才是芒格式烟蒂的入场区**——现价 $3.64 仍贵了 45-70%。**"极度便宜"只有在"现金是真的"时才是便宜；现金出不来，烟蒂就抽不了。**

**一句话：** 信也是一门"利润来源正在被监管关闭、资产负债表正在变重、现金可能够不着"的生意——3.32x PE 不是市场犯错，是市场在正确地给"正在融化的资产"定价。**芒格会把它放进"太难"的篮子：等到条件 1-5 中至少 3 条验证、价格进入 $2.5 以下，再拿出来重新审视。在那之前，15% 的股息率是诱饵，不是回报。**

## 投资吸引力总评分：★★.25（2.25 / 5）

**扣分项**：结构性监管风险（息费透明化直击利润根源）、现金可支配性存疑（¥93亿受限 + 可转债实锤）、OCF 转负与表内化（现金变风险资产）、租来的护城河、P2P 历史包袱——芒格框架下这些是"出局级"缺陷。

**加分项**：价格已极度便宜（PB 0.35x、PE 3.32x 隐含了大部分悲观预期）、业务仍在盈利（TTM 净利 ~$2.59亿）、部分现金真实可动用、PCAOB 审计问题已解决（2022-12 解除）、信也未在 3/13 约谈名单中。

**平衡判断**：2.25/5——**"有条件关注的烟蒂，不是芒格式好生意"**。条件 1（OCF 转正 + 分红自给）与条件 4（监管定价明朗）任一兑现，评分升至 3.0；若 2026 下半年 OCF 继续为负或约谈名单扩大，降至 1.5。**记住：在错误的条件被验证之前，3.3x PE 可以是价值陷阱，也可以是机会——而芒格只在验证之后下注。**
