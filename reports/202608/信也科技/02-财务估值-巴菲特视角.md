# 02-财务估值分析：巴菲特视角

> **分析对象**：信也科技（FinVolution，NYSE: FINV）——中国助贷平台
> **分析日期**：2026-08-28（收盘 $3.64，Q2'26 财报后 -9.45%；52 周区间 $3.81-6.87）
> **市值**：$859M（235.93M ADS，USDCNY 6.78）
> **评级**：★★★.5（3.5/5）——「以烟蒂价格买一家现金真实但部分被困、盈利收缩的重资化助贷平台」
> **核心矛盾**：安全边际（巴菲特第一原则）极厚 vs 生意质量（第二原则）不达标且在恶化

---

## 一、DuPont ROE 拆解（含 TTM）

| 年份 | 净利率 | × 资产周转率* | × 权益乘数* | = ROE |
|------|:---:|:---:|:---:|:---:|
| FY2021 | 26.3% | 0.70 | 1.27 | **23.4%** |
| FY2022 | 20.1% | 0.74 | 1.24 | 18.4% |
| FY2023 | 18.6% | 0.71 | 1.28 | 16.9% |
| FY2024 | 18.2% | 0.60 | 1.43 | 15.6% |
| FY2025 | 18.7% | 0.60 | 1.39 | 15.6% |
| TTM | **14.5%** | 0.63 | 1.25 | **11.4%** |

> *资产周转率/权益乘数为按披露结构（表内贷款、现金、净资产）推算值，非精确审计数，尾差源于平均/期末权益口径。

**巴菲特式定性：这是「坏下降」，不是「好下降」。**
- **净利率是绝对主导变量**：26.3% → 14.5%，压缩 11.8pct，解释了 ROE 下滑（-12pct）的约 98%。FY22 大跌是监管冲击（利率压降、客群上浮），FY25→TTM 再跌是表内贷款扩张带来的拨备与资金成本。
- **杠杆上升救不了 ROE**：权益乘数 FY21 1.27 → FY24 峰值 1.43（表内贷款 3,873→9,493，+145%），但 ROA 从 18.4% 腰斩到 9.1%——**加杠杆的同时资产回报崩塌，是典型的盈利质量恶化信号**。TTM 乘数回落至 1.25 更说明：表内扩张已到资本约束边界，无法再靠杠杆续命。
- **ROE 11.4% 处于「平庸生意」区间**（Ke=12% 以下），且方向向下——巴菲特不会为这种趋势付溢价，只会为它的价格付钱。

## 二、现金流质量评估（利润是意见，现金是事实）

| 指标（RMB M） | FY2021 | FY2022 | FY2023 | FY2024 | FY2025 | TTM |
|------|:---:|:---:|:---:|:---:|:---:|:---:|
| OCF | 630 | 237 | 1,361 | 2,893 | 1,868 | 531 |
| OCF/NI | 0.25 | 0.10 | 0.58 | 1.21 | 0.73 | **0.28** |
| 表内贷款 | 3,873 | 4,354 | 3,336 | 6,581 | 8,537 | 9,493 |

- **五年累计 OCF/NI ≈ 0.6**：每赚 1 元账面利润，只收回约 0.6 元现金。FY24 的 1.21 是唯一达标年份，随即回落——现金流确认极不稳定，助贷「先垫后收」+ 表内放贷共同造成。
- **TTM OCF/NI 0.28 是五年最差**：主因是表内贷款扩张——**现金正在变成风险资产**。每一块钱投入表内贷款，都从「流动性资产」转为「依赖借款人还款的信用资产」。
- **巴菲特警示**：表内贷款 9,493 = 净资产的 57%。公司把轻资产撮合生意（赚服务费）改造成了重资产放贷生意（赚利差+担风险）。历史上助贷表内化的公司，利润表总是先好看、减值总是后到——**TTM 净利率 14.5% 是否已充分计提，是这份报表最大的问号**。

## 三、现金真实性审计结论（用户重点关注）

| 科目 | 金额（RMB M） | 性质 | 可支配性评级 |
|------|:---:|------|:---:|
| 现金及等价物 | 3,259 | 银行存款 | ★★★★ 部分受限 |
| 短期投资 | 3,162 | 银行定期 + 理财 | ★★★★ |
| 受限现金 | 1,632 | 代收借款人资金 1.2 / 信托待分配 6.0 / 托管 8.6 / 待付资金方 3.8 亿——**全部为过路资金** | ☆ 不可用 |
| 合计账面 | 8,053 | | |
| **净现金**（减总债务 1,575） | **4,846 = $715M = 市值 83% = $3.03/ADS** | | |

**真实性：高（可信）。** 普华永道中天审计、内控有效、无保留意见；受限现金逐项有明细且均为代收代付过路资金；关联方应收仅 ¥0.37 亿（极小）。**没有藏雷的迹象。**

**可支配性：需打折（核心折价项）。**
- 20-F 披露境内受限金额（子公司实收资本+法定公积金+VIE 净资产）合计 **RMB 93 亿，比现金总额还大**；
- 现金分布（FY25 末）：开曼 ¥0.98 亿 + 离岸子公司 ¥23.6 亿（**可自由支配**）+ WFOE ¥1.37 亿 + VIE ¥16.9 亿（境内，仅能经 WFOE 分红出境——受 PRC GAAP 留存收益、10% 法定公积金、SAFE 审核、外汇管制四重限制）；**VIE 净资产无法律所有权**；
- **实锤**：2025-06 坐拥 ¥73 亿现金仍发行 $150M 可转债（2.5%，2030 到期，2028-07 可回售）为境外回购分红提供美元——**境内现金无法自由出境是事实，不是猜疑**；
- **但部分可回流**：分红已连续 8 年逐年提升、H1'26 回购 $66.8M——境外资金 + 部分境内利润确实在支撑股东回报。

> **SOTP 处理（引用主会话）**：境外 48% 现金全额 + 境内 52% 折价 40% - 全部债务 = **调整净现金 $2.19/ADS**（对应约 ¥35.1 亿可支配口径）。

## 四、估值框架（截至 2026-08-28，$3.64）

| 指标 | 数值 | 判断 |
|------|:---:|------|
| PE（TTM） | **3.32x** | 历史极低（常态 4-6x）；但注意盈利在下滑 |
| PB | **0.35x** | 破净 65%（BVPS $10.47），清算价值大幅折价 |
| PS（TTM） | 0.44x | 极低 |
| 股息率 | **8.4%** | $0.306/ADS，连续 8 年提升 |
| ROE（TTM） | 11.4% | 自 23.4% 持续下滑，低于 Ke=12% |
| PEG | 不适用 | TTM 净利 -25%，市场按「永久衰退」定价 |
| 股东总回报率 | **~24%/年** | 股息 8.4% + 回购年化 ~$133M（市值 15.5%） |

**PEG 判读**：净利负增长使 PEG 失真——这不是「便宜的好公司」，而是「便宜的收缩公司」。估值的锚不在成长，而在**资产折价 + 股东回报 + 经营企稳假设**。

## 五、内在价值三情景（引用主会话估值模型，禁止重算）

| 情景 | 假设（调整净现金 $2.19/ADS + 正常化盈利×倍数） | 目标价 | vs 现价 |
|------|------|:---:|:---:|
| **悲观** | 正常化净利 ¥13 亿 × 4x | **$5.45** | +50% |
| **中性** | 正常化净利 ¥17 亿 × 6x | **$8.57** | +135% |
| **乐观** | 正常化净利 ¥22 亿 × 8x | **$13.20** | +263% |

**交叉验证（主会话）**：
- ROE→P/B（Ke=12%）：ROE 15%→$13.08 / 12%→$10.47 / 10%→$8.72 / 8%→$6.98；**当前 ROE 11.4% 对应约 $9.95**；
- 股息折现（$0.306，Ke=8%）：g=0%→$3.82 / g=2%→$5.10 / g=4%→$7.65。

**折价假设说明**：SOTP 已对境内现金折价 40%——若未来 VIE 分红通道打通或结构重组使境内现金可全额出境，仅现金项就有从 $2.19 上修至 $3.03+ 的空间；反之若监管进一步限制分红出境，$2.19 仍有下修风险。**现价 $3.64 恰好低于悲观情景 $5.45 约 33%——市场比最悲观的分析师还悲观。**

## 六、安全边际判断（现价隐含什么预期）

**现价拆解**：$3.64 = 调整净现金 $2.19 + **经营业务定价 $1.45/ADS**（≈ $342M ≈ ¥23 亿 ≈ **1.1x TTM 净利**）。若按账面净现金 $3.03 全额计，经营业务仅被定价 **$0.61/ADS（≈0.5x TTM 净利、0.15x 账面价值）——市场按「经营业务价值 ≈ 0」定价**。

| 检查项 | 结果 |
|------|------|
| 现价 vs 中性 SOTP $8.57 | ✅ 折价 58%，安全边际厚 |
| 现价 vs 悲观 SOTP $5.45 | ✅ 仍折价 33% |
| 净现金占市值 | ✅ 83%（$3.03/ADS） |
| 股息率 8.4%（连续 8 年提升） | ✅ 下行有息保护 |
| DDM g=0% → $3.82 | ⚠️ 现价 ≈ 零增长分红价值——**上涨必须靠 g>0 或估值修复** |
| 隐含的市场预期 | ⚠️ 表内贷款 94.9 亿将暴雷 + 境内 93 亿受限资产永不回流 + 监管再压缩 |

**巴菲特式判断**：这是一个「下有保底（净现金+股息托底）、上有弹性（+50%~+263%）」的典型烟蒂结构。**但 DDM 零增长值 $3.82 ≈ 现价说明：市场没有定价错误到离谱，而是把「分红永不增长」当了基准情景**——安全边际的兑现，取决于经营企稳（OCF/NI 回升、表内扩张放缓），而非简单的估值回归。

## 七、巴菲特式结论

- **这不是巴菲特理想中的生意**：护城河受监管压制、ROE 11.4% 且下行、净利率五年压缩 12pct、OCF/NI 0.28、重资产化吞噬现金——「伟大生意」的全部特征都不具备。
- **但这是巴菲特理想中的价格**：PB 0.35x、股息率 8.4%、净现金=83% 市值、PE 3.3x。**用「烟蒂价」买「平庸生意」，安全边际完全来自资产端而非盈利端。**
- **一美元原则裁决**：过去 5 年留存收益（累计净利约 ¥110 亿 - 分红回购）大部分沉淀为表内贷款与境内受限现金，同期市值缩水——**留存收益未创造等量股东价值，资本配置效率为负**；管理层唯一的加分项是分红连续 8 年提升 + 回购纪律（年化回报 ~24%），弥补了配置失误。
- **风格定性**：这是施洛斯/格雷厄姆口袋里的机会，不是芒格式的「伟大公司合理价」。巴菲特会**「适度仓位买入，吃 8.4% 股息 + 等修复」**，而重仓加码需要看到两个证据：OCF/NI 回升至 0.7+、表内贷款增速显著放缓。核心风险是**价值陷阱**——若信贷周期反转使表内减值爆发，账面利润与现金会同时被侵蚀，$3.64 的「便宜」会变成「贵」。

## 八、投资吸引力总评分：★★★.5（3.5/5）

| 维度 | 评分依据 |
|------|------|
| 估值水平 | 极低（PE 3.3x / PB 0.35x / 股息 8.4%）——**满分项** |
| 资产负债表 | 净现金=83% 市值，普华永道审计、明细清晰——**强** |
| 现金可支配性 | 境内 52% 被困（VIE 结构 + 93 亿受限），已折价 40% 处理——**弱项** |
| 生意质量 | 净利率 26.3→14.5%、ROE 23.4→11.4%、重资产化——**弱项** |
| 现金流质量 | 五年 OCF/NI ≈0.6、TTM 0.28——**弱项** |
| 股东回报 | 股息 8.4% + 回购 ~15.5%，连续 8 年提升——**强** |
| 安全边际 | 现价低于悲观情景 33%、低于中性 58%——**极厚** |

**总评**：安全边际（第一原则）极厚、资产真实（经审计验证）、股东回报纪律优秀——三项撑起 3.5 星；但生意质量恶化、现金部分被困、现金流质量差——三项封住 4 星。**这是「深度价值/烟蒂式买入区间」：适合价值型投资者以股息+修复逻辑持有，不适合成长型投资者；$3.64 具备吸引力，但重仓必须等 OCF/NI 与表内贷款增速的拐点证据。**

> **一句话**：用 0.35 倍账面价值、3.3 倍盈利的价格，买一家现金真实（83% 市值）、回报慷慨（~24%/年）、但生意在收缩的平台——**巴菲特的答案是：可以买，仓位别重，耐心等修复。**
