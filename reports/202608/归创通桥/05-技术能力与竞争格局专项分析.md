# 归创通桥（2190.HK）技术能力与行业竞争格局专项分析

> 报告日期：2026-08-06 ｜ 补充于《归创通桥-四大师综合报告》之后（综合评分 3.74/5）
> 本报告聚焦两个问题：①归创通桥的技术能力在行业里处于什么水平？②神经介入+外周血管介入的竞争格局如何演变，归创通桥的位置在哪里？

## 一、技术能力全景

### 1.1 研发投入：器械行业第一梯队强度

| 年度 | 研发费用（RMB） | 占收入比 | 说明 |
|------|:---:|:---:|------|
| 2023 | ~1.5亿（估） | ~29% | 上市后高强度投入期 |
| 2024 | ~2.3亿（估） | ~29.8%（年报口径） | 首度盈利年份仍保持高研发强度 |
| 2025H1 | 1.2亿（+19.7%） | ~24% | 官方披露 |
| 2025全年 | ~2.6-2.8亿（估） | ~25% | 规模效应下占比回落但绝对额上升 |

> 研发强度（~25-30%）显著高于传统械企（10-15%），与微创脑科学、心玮医疗同处国产创新第一梯队。**注意：2024年报研发占比29.8%是行业罕见的高强度——这解释了其产品线宽度。**

**归创通桥的核心技术资产是"神经介入+外周血管介入"双平台，这在国产厂商中是独一份的宽度：**

### 1.3 技术能力的三个真问题

**① "First or Best？"——产品差异化深度不足（最尖锐的批评）**

> 雪球/华盛通深度文章《介入江湖——双管齐下的归创通桥》直言：**"核心产品既非FIRST，也非BETTER，更难言BEST。"**
> - 蛟龙取栓支架：国产最早出海（2020 CE），但国内取栓市场美敦力Solitaire/史赛克Trevo仍是金标准，蛟龙是"跟随者"
> - 麒麟密网支架：技术有亮点（远端闭合+全显影），但上市时间晚于微创Brainbridge、泰杰Lattice
> - UltraFree DCB：价格最低（集采以价换量），非技术领先

**② 原材料国产化率90% = 成本护城河，不是技术护城河**

90%国产化让归创在集采下毛利率仍守住72%——这是**成本优势**（供应链本土化），与外资的**技术代差**（材料学、涂层工艺）是两回事。真正的技术壁垒（如密网支架的金属疲劳性能、DCB的药物涂层控释）仍在外资手里。

**③ 平台宽度 ≠ 单品深度**

双平台覆盖"动静脉全谱系"是战略宽度优势（分散风险、集采对冲），但代价是**每个细分单品都面临专注型对手**：密网支架对泰杰Lattice（11000套植入/800家医院）、ICAS支架对赛诺（41%销量第一）、抽吸对微创/心玮。

### 1.4 技术能力评级

| 维度 | 评级 | 依据 |
|------|:---:|------|
| 研发投入强度 | ★★★★ | 25-30%收入，行业第一梯队 |
| 产品管线宽度 | ★★★★½ | 双平台60+产品管线，国产最全 |
| 单品技术深度 | ★★★ | 多数产品为"跟随+微创新"，缺重磅首创 |
| 临床证据积累 | ★★★½ | 蛟龙海外临床89.4%再通率；麒麟对标Pipeline数据发布 |
| 供应链/成本 | ★★★★½ | 原材料国产化90%，集采毛利率72% |
| **综合技术能力** | **★★★¾（3.75）** | 平台宽度+成本控制是强项，单品首创性是短板 |

### 2.4 集采：格局重塑的加速器

**2025年神经介入三大联盟集采（这是理解格局的关键）：**
- 吉林21省联盟：弹簧圈
- 河北牵头三明联盟：颅内支架
- 京津冀"3+N"联盟：取栓支架、血栓保护装置

**集采的赢家逻辑：**
1. **国产以价换量**：弹簧圈国产份额 2020年3.85% → 2022年17% → 持续攀升；归创弹簧圈 0.27%→10%
2. **外资"以集采保份额"**：2025年格局或仍是美敦力第一——头部外资积极参采，未溃败
3. **河南联盟报量**（2025）：史赛克17% / 美敦力13% / 强生8% / 瑞康通8% / **归创6%**（国产第二）
4. **归创中标面最广**：2025年初麒麟密网、白驹颅内PTA球囊、三款外周球囊同时中标

> **核心判断**：集采不是"国产替代"的免费午餐，而是**"以价换量+份额洗牌"的双刃剑**。归创是当前阶段的最大赢家之一（毛利率72%纹丝不动+份额提升），但这建立在成本优势（90%国产化）之上，而非技术代差。

### 2.5 竞争格局的三大趋势

| 趋势 | 含义 | 归创应对 |
|------|------|------|
| **① 集采常态化 → 利润向头部集中** | 小厂商被价格战出清，头部（归创/微创）凭规模+成本胜出 | 双平台最全组合对冲单品降价 |
| **② 出海成为第二曲线** | 国内集采压制单价，海外高毛利 | 收购德国Optimed获欧洲渠道（2026）；韩国/东南亚/马来西亚布局；海外销售2025 +100% |
| **③ 资本厚度决定终局** | 神经介入并购潮（2025年半年49笔），现金为王 | **可动用资源25亿+**（vs 微创脑科学现金5.62亿、沛嘉6.12亿）——并购整合的弹药最足 |

## 三、综合评估

### 3.1 技术能力 vs 竞争格局：归创的真实位置

| 评估项 | 结论 |
|------|------|
| **技术能力** | ★★★¾（3.75）：平台宽度国产第一、成本控制优秀、临床证据扎实；但单品首创性不足（"跟随+微创新"为主） |
| **竞争格局地位** | 国产第二梯队头部（营收/净利/现金流均国产第一）；细分上：弹簧圈集采赢家、取栓出海先锋、密网追赶者、ICAS空白 |
| **最大优势** | 双平台60+产品组合 + 25亿现金弹药 + 72%毛利率的成本底气——集采时代的"全能选手" |
| **最大短板** | 缺乏"人无我有"的重磅首创单品；密网支架被泰杰Lattice甩开（11000套 vs 麒麟起步）、ICAS赛道空白 |

### 3.2 与四大师结论的衔接

- **段永平视角印证**："集采洗牌赢家"的判断有技术支撑——成本优势（90%国产化）是72%毛利率的根基
- **李录视角印证**：国产替代趋势真实存在（弹簧圈3.85%→17%→持续），但天花板在高端品类（外资技术代差仍存）
- **芒格视角警示**：本报告揭示了一个四大师报告未展开的风险——**平台宽度可能稀释单品深度**，每一细分都面对专注型对手（泰杰/赛诺/先瑞达），"全能"在集采价格战里可能是"全而不强"

### 3.3 关键跟踪指标

1. **麒麟密网支架的医院覆盖与植入量**（vs 泰杰Lattice 11000套的差距能否缩小）
2. **Mammoth抽吸导管能否在抽吸赛道撕开口子**（vs Penumbra/微创）
3. **弹簧圈份额10%能否继续爬升**（第二轮集采价格）
4. **Unicorn/Octoplus等出海新品注册节奏**（韩国/马来西亚→欧洲）
5. **Optimed并表后的欧洲渠道收入**

## 四、AlphaFind 终极一问

> **归创通桥用"双平台60+产品的宽度"在集采时代活了下来、并且活得很好——但宽度的另一面是：它在每一个细分赛道里都不是第一（弹簧圈输给沛嘉的量、密网输给泰杰的先发、ICAS干脆缺席、抽吸刚起步）。**
>
> **当集采把"以价换量"的红利吃完、行业进入"单品深水区"竞争时，一个"全而不强"的全能选手，和一个"单品称王"的专注选手，谁会笑到最后？归创通桥的2.44亿净利，究竟是平台协同的效率红利，还是每个单品都在给对手当陪跑的错觉？**
