## 三、各大师视角摘要

### 段永平（2.75★）：不是一门"本分"的好生意

- 生意本质："把租来的 IP 用低价积木人变现的 IP 搬运工+供应链组织者"
- 与乐高/万代/泡泡玛特的差距在**IP 独占性**：乐高自有 IP+专利体系、万代是 IP 原厂、泡泡玛特自有艺术家 IP 生态（IP 运营投入占营收 15.7%），布鲁可 50+ 个 IP 全是租来的且不独家
- 管理层"对的人"存疑：能力一流（游族背景、3 轮融资 18 亿、执行力强），本分存疑（上市前套现、天价薪酬、向经销商压货的嫌疑）
- 结论：**"不懂不做"**。跟踪指标：自有 IP 占比能否破 50%、毛利率能否止跌

### 巴菲特（3.25★）：质量与价格的赛跑

- DuPont：21.8% 净利率 × 0.71x 周转 × 1.44x 杠杆 = 22.1% 真实 ROE（报表 99.9% 是期初净资产为负的统计假象）
- 现金流：OCF/NI 1.40x 优质，但存货周转 28→75 天 + 模具折旧 +64.3% + 自建工厂 CapEx 上行是三大消耗信号
- 估值：PE(TTM) 26.4x 较泡泡玛特 ~20x 贵 32%；PE/ROE = 1.19（>1，偏贵）；PEG 0.7-0.86 看似便宜但 G 正被 9.9 元策略侵蚀
- 三情景 DCF：乐观 129 / 中性 91 / 悲观 60 HKD；中性上行 +24% vs 悲观下行 -19%，盈亏比 1.3:1，"勉强及格"，不符合"0.5 买 1"的标准
- 均值回归警示：若 ROE 回落至 18% 且市场按 20x 定价，股价需跌 31-38%（高 ROE+高 PE 双高叠加的双倍杀伤力）
- 结论：**"可观察、不可重仓"**。等待信号：毛利率环比回升、海外占比超 30%

### 芒格（3.25★）：已经崩过一次，还会再崩吗？

- 已发生的崩盘：198 → 39.2 HKD（-80%），"租来的 IP、别人的渠道、越来越薄的毛利"剧本已经演过一遍
- 8 条可信失败路径（概率最高的四条）：
  - **低价策略吞毛利（45%）**：9.9 元销量占 47.6% 收入仅 19.5%，正在发生
  - **解禁减持洪峰（40%）**：机构股东约 17%（君联/源码/云锋/高榕），2026 年起解禁
  - **叙事退潮（40%）**：泡泡玛特行情退潮、资金审美迁移
  - **授权 IP 断供（30%）**：奥特曼 2027 到期 + 变形金刚非独家
- 能力圈判断：布鲁可是"租 IP+代工+经销"生意，赚的不是 IP 的钱，在能力圈边缘
- 最担心的两个问题：①你拥有的 IP 是你自己的吗？（61% 收入系于授权 IP）②增长是赚来的还是买来的？（毛利率连降+压货嫌疑）
- 结论：**"避免愚蠢比追求聪明更重要"**——悲观 DCF 60 以下才是避免愚蠢的价格

### 李录（3.25★）：长坡、薄雪

- 赛道判断：拼搭玩具是百年品类（乐高 90 年验证），但布鲁可的雪是租来的（授权 IP 占 85%）
- 行业天花板（定量）：全球拼搭角色类 600-750 亿 RMB（CAGR 10-12%）；中国渗透率 5.5% vs 日美 15-20%；三情景 2033 年营收：保守 75 亿 / 中性 130 亿 / 乐观 208 亿
- 竞争格局：波特五力中**授权方议价力 + 经销商议价力双高**；全球四梯队中布鲁可处第四梯队（差距 4-20 倍）
- 20 年增长模型（保守假设）：国内 5%/3%/2%、海外 25%/15%/8% 三阶段，2045 年营收 137 亿/净利 24.7 亿，年化仅 3-4%——**全部超额回报押注海外**
- 结论：看得懂但有看不清的变量（IP 所有权/渠道健康度/定价权）；两个验证点：2027 年奥特曼到期换挡能力、海外连续 3 年 ≥50% 增长 + 毛利率企稳 45%+

## 五、事件驱动补充：2026 中期业绩（2026-08-12 盘后发布）

- **8 月 13 日 +19.7%、8 月 14 日 +3.7%，两日合计 +24%**：市场对中报的即时定价
- 亮点：海外 +228.5%（占比 8.3%→20.6%，美洲 +349%）；载具类新品放量（1.86 亿，占 10.4%）；净利 +30.6% 与营收同步
- 隐忧：毛利率 44.3% 创近年新低（-4.1pct）；9.9 元产品销量占 47.6% 但收入仅 19.5%；国内收入增速仅 +14.9%
- 解读：**中报确认了"海外+载具类"的第二增长曲线，但也确认了"低价走量侵蚀盈利中枢"的第一性矛盾**——市场给了 24% 的涨幅，因为它第一次看到了增长质量的切换证据；但毛利率曲线仍在向下

## 六、AlphaFind 终极一问

布鲁可用 18 个月完成了从奥特曼到变形金刚的 IP 换挡（63.5% → 28% vs 33%），证明了"授权搬运工"的执行力——但这是**搬运工**的胜利。

**当奥特曼授权 2027 年到期、变形金刚也必然进入生命周期后段时，布鲁可能否在自有 IP（英雄无限/繁星集结）上复刻泡泡玛特"IP 资产化"的路径，让 IP 从"租来的成本项"变成"自己养大的资产项"？还是永远停留在"授权搬运+渠道效率"的利润模式——你买的到底是"中国版泡泡玛特"的期权，还是"玩具界蜜雪冰城"的现实？**
