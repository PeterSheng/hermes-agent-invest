## 三、各大师视角摘要

**段永平（商业模式）**：Intuit 是"税+账"两座收费站的订阅制收租者——TurboTax 在美国报税的心智垄断（份额 ~60%+）、QuickBooks 的小企业会计生态锁定（会计师渠道+支付+工资）、Credit Karma 的数据网络效应。好生意三问：①好生意✅但正在过弯——80.8% 毛利率、37% FCF 利润率，但报税季 TurboTax 增速从双位数掉到 +7%；②管理层基本是对的人——Goodarzi 2019 年起营收近三倍、主动拥抱 AI（Anthropic 2026-02 合作）；③好价格✅——60x→22x 十年最低，市场已按 FCF 停滞定价。关键提醒："靠游说赢的护城河（IRS Direct File 之死）不算真护城河"。结论：观望偏买，先建 ≤5% 观察仓，等"报税增速回双位数、SBC 降到 7% 以下、AI 提价可量化"三信号兑现两个再加仓至 10-15%。

**巴菲特（财务估值）**：DuPont 拆解——ROE 从 FY2022 并购低点 15.7% 连续四年修复至 22.5%，是净利率修复驱动（非杠杆）；商誉 $18.8B（占资产 48%，Credit Karma/Mailchimp 遗留）压低资产周转 0.53，**真实经营回报看 ROIC 20.6%**。现金流质量极优：OCF/NI 1.72x、FCF 利润率 37.1%、CapEx 占营收 <1%；**但 SBC $2,039M 占营收 9.7%——修正后真实 FCF $5,716M、真实 FCF Yield 5.8%**。三情景 DCF（WACC 9.5%）：悲观 $277.63 / 中性 $553.06 / 乐观 $884.23；概率加权 IV ≈$567（+36%）；现价隐含永续增速仅 1.7-3.7%（市场定价 FCF 停滞），与指引 +12-13% 错位。结论：私有公司出价 $500-550/股，现价有安全边际，逢低买入区间 $280-360。

**芒格（逆向风险）**：八条失败路径——AI 免费报税夺 TurboTax（40%）、AI 记账代理旁路 QuickBooks（30%）、TurboTax 诉讼（25%）、IRS Direct File 复活（20%）、商誉减值 $18.8B（15%）、小企业衰退（30%）、戴维斯双杀（30%）、SBC 持续侵蚀。两大核心担忧：①**路径依赖**——"报税季现金牛"（Q3 单季 $4,364M ≈ 消费者收入 90%）让 Intuit 收"复杂性的租金"，而 AI 的使命正是消灭复杂性（柯达/Blockbuster 类比）；②**激励错位+游说依赖**——$53.8M 游说买"租来的护城河"，SBC 9.7% + 非 GAAP 比 GAAP 高 40%。概率加权：基准权重 EV ≈$493（+36%），保守权重 +24%——**AI 联合概率 25-30% 高于 ADBE，赔率弱一档**。结论：正期望的错杀，分批建仓、$277 以下加码、盯紧两大先行信号（报税增速、AI 提价）。

**李录（长期趋势）**：报税（法律刚需）+记账（商业刚需）+信用（金融刚需）三大文明级支柱；税法复杂化是"立法者行为"，只会越来越复杂。20 年置信度 4.35/5（需求 4.75 / 技术代际 3.75 / 竞争 4.50 / 管理层 4.25 / 商业模式 4.50），P(20 年后仍为领导者) ≈ 75-80%。TAM：美国本土 $600-2,100 亿（报税 $150-200 亿 + SMB $300-1,600 亿 + Credit Karma $100-300 亿），渗透率仅 10-35%。20 年保守模型：CAGR 6-8% → 2046 年营收 $670-970 亿、FCF $250-360 亿，对比现价隐含 FCF 停滞 $62.5-72.8 亿。结论：**"机会，十年一遇的定价错位"**——PE 22x 十年最低分位，风险收益比 1:2.3，中性 IV $553 vs 现价 $362。

## 六、关键矛盾与观察清单

**核心矛盾**：**市场定价的"AI 免费化终结 Intuit" vs 基本面显示的"增速放缓但仍在 12-15% 增长"**——
- 空头：Perplexity/ChatGPT 类 AI 免费报税随时可能出现；AI 记账代理直接对接银行/IRS，QuickBooks 沦为被绕过的中间人；TurboTax 报税季增速已掉到 +7%（第一个裂缝）；SBC 9.7% 稀释；60% 报税份额是"等着被免费 AI 烧掉的存量"
- 多头：IRS Direct File 已死（政策性威胁解除）；与 Anthropic 合作把 AI 变成提价引擎而非威胁；QBOA +17.4%、Online Services +12.3%、Credit Karma +16% 都健康；80.8% 毛利率 + 37% FCF 利润率 + 净现金的印钞机属性未变；**22x PE 已把 AI 颠覆当成基准情景定价**（隐含 FCF 停滞 vs 实际 +26% 增长）

**跟踪清单**：① **8/25 Q4 FY2026 财报**（本周！）：FY2026 营收能否达指引下限 $20,997M、Q4 增速、FY2027 指引；② TurboTax 2027 报税季（2027-02~04）增速能否回双位数；③ AI 提价可量化性：Intuit Assist/Anthropic agents 的付费转化与 ARPU；④ SBC 占营收比例趋势（9.7% 是否下降）；⑤ Credit Karma 变现深化；⑥ 美国小企业景气与利率环境。
