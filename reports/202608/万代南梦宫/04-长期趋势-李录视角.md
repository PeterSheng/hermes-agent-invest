## 文明级赛道判断

**"IP 娱乐消费"是人类文明级的确定性赛道——** 从手办到主题乐园，人类对"故事+角色"的付费欲望跨越文化、代际与收入阶层。日本 IP 产业（动漫/游戏/玩具）已验证 50 年全球输出能力：高达（1979）、龙珠（1984）、海贼王（1997）至今仍是全球顶级 IP。**万代南梦宫站在这个赛道的最核心位置：它既是内容创作者（动画/游戏），又是 IP 资产持有者（高达等自有 IP），还是最大变现管道（玩具/一番赏/扭蛋）。**

李录式判断框架：确定性来自"人类对娱乐的消费是长期刚需 + 日本 IP 全球渗透率仍低"；风险在于"IP 热度的代际轮换"。

## 20 年置信度评估

| 维度 | 置信度 | 依据 |
|------|:---:|------|
| 赛道存续 | 95% | 娱乐消费刚需，动漫/玩具市场百年长青 |
| 公司存续 | 90% | 净现金 ¥4,211亿、无杠杆、多元化 IP 组合，资产负债表可扛任何周期 |
| IP 资产保值 | 80% | 高达 47 年 + 龙珠/海贼王 30-40 年，头部 IP 半衰期极长（对比：多数游戏 IP <10 年） |
| 增长兑现 | 60% | 全球化+新 IP 孵化是真实引擎，但游戏内容波动会侵蚀复利平滑度 |
| 管理层能力延续 | 70% | 日本企业治理稳健但保守，资本配置（派息率 33.6%）偏吝啬 |

**20 年置信度综合：~75%**——属于"高确定性赛道中的优质资产"，但低于消费垄断型（如可口可乐式 90%+），因为内容产业本质有"口味漂移"风险。

### 增长驱动（三大引擎）

1. **日本 IP 全球化**：2020 年代日本动画全球流媒体爆发（Netflix/Crunchyroll 采购），《鬼灭之刃》《咒术回战》证明日本 IP 可全球变现。万代海外营收占比仅 28%（美国 9%/欧洲 9%/亚洲 10%）——**海外是最大增量**（泡泡玛特已证明亚洲潮玩消费力，万代在东南亚/北美份额尚低）。
2. **成人收藏市场**：Gunpla（高达模型）海外成人玩家扩张 + 一番赏/扭蛋出海——FY2022→FY2026 玩具营收 3,736→6,740 亿日元（年化 16%），其中海外是主引擎。
3. **IP 共创与新 IP**：GQuuuuuuX（与 Khara 共创，2025 剧场版破百亿日元票房）验证了"共创模式"；偶像大师、赛马娘（授权）等新 IP 证明孵化能力。

### 制约因素

- 日本出生率下降 → 儿童玩具基本盘萎缩（万代已靠成人化对冲）
- 中国潮玩竞争（泡泡玛特自有 IP 生态 + 全球扩张）挤压亚洲周边市场
- 游戏市场向"服务型/大 DAU"集中，单机 IP 游戏变现天花板受限
- 授权 IP（龙珠/海贼王）的续约与内容供给依赖 IP 方（集英社/东映）

## 李录式结论

**"20 年后，人类一定还在消费 IP，万代南梦宫大概率还在其中——但它的复利速度不会让你惊讶。"**

万代南梦宫符合李录"长期确定性"框架：赛道（IP 娱乐）确定性 95%、公司存续确定性 90%、资产（IP）半衰期极长。这是可以"拿 20 年不睡觉"的公司质地。但两个保留：①增速天花板明确（玩具市场个位数增长，万代需要不断靠新爆款 IP 维持 10%+ 增速，而爆款不可规划）；②管理层资本配置保守（33.6% 派息率 + 1.3% 股息率，对长期股东不算慷慨）。

**长期买点**：李录框架下，"好公司"也要"好价格"。合理的长期买点是 PE 15-18x（对应 ¥3,100-3,800，历史中枢下沿），届时股息率升至 2-2.3%、FCF Yield 5%+，长期持有年化回报可达 10%+。现价 ¥5,687（PE 24x）透支了 3-4 年的增长。

**评分：★★★.50 / 5**（确定性 3.75，价格折价 3.25）
