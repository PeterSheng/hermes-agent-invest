## 三、增长路径分析

### 3.1 三条核心增长路径

#### 路径 A：承保端 — 保费有机增长（确定性：⭐⭐⭐⭐）

```
增长引擎：
  1. 中小企业商业险（Select Accounts）：+4-5%/年
     → 美国中小企业数量持续增长，保险渗透率提升
  
  2. 中型企业商业险（Middle Market）：+3-4%/年
     → 经济扩张 + 保险需求刚性
  
  3. 个人车险/房险：+2-3%/年（加拿大退出后）
     → 定价优化 + 客户留存率提升
  
  4. 债券与特殊险：+5-7%/年
     → 基建投资 + 网络安全保险高增长

整体保费增速预期：
  保守：3-4%/年（软市场 + 加拿大退出影响完全体现）
  中性：5-6%/年（温和硬市场延续 + 精选增长）
  乐观：7-8%/年（硬市场持续 + 市场份额提升）
```

#### 路径 B：投资端 — 浮存金复利（确定性：⭐⭐⭐⭐）

```
当前状态：
  投资资产：$103.2B
  组合构成：~90% 固定收益（投资级企业债+市政债+国债）
  久期：~4-5年
  年化 NII：$3.3-3.5B（税后）
  投资收益率：~3.3-3.5%

增长引擎：
  1. 浮存金自然增长（保费增速 → 投资资产增速）
     → 浮存金每年增长 $3-5B → 即使收益率不变，NII 增长 3-5%
  
  2. 再投资收益率提升（高利率锁定效应）
     → 低息旧债到期 → 再投资于高息新债 → 收益率逐步抬升
  
  3. 组合久期优化
     → 在利率高点延长久期，锁定高收益

投资收入增速预期：
  保守：0-2%/年（利率下行 + 再投资收益率下降）
  中性：3-5%/年（浮存金增长 + 利率缓慢下行）
  乐观：6-8%/年（浮存金增长 + 利率维持高位）
```

#### 路径 C：资本配置 — 股份回购引擎（确定性：⭐⭐⭐⭐⭐）

```
这是TRV最确定的增长引擎：

2025年：回购约 $20亿（减少 ~2.5% 股份）
2026年Q1：回购约 $20亿（单季！加速中）
加拿大出售额外 $7亿回购

股份减少速度：
  保守：2%/年
  中性：4%/年  
  乐观：5-6%/年

→ EPS 自动增长 2-6%/年，即使净利润零增长

逻辑链条：
  承保利润 → 回购 → 每股权益增加 → BVPS 增长 → EPS 增长
  这是一个自增强的复利飞轮
```

## 四、DCF估值（三情景）

### 4.1 方法论说明

> ⚠ **保险公司的 DCF 有天然缺陷**：保险公司并非传统意义上的"自由现金流"企业——浮存金的复杂性和资本要求使得标准 FCF 定义存在争议。因此，我们采用 **"可分配利润"（Distributable Earnings）** 作为 DCF 的现金流代理，并同时提供 **P/B-ROE 框架估值**作为交叉验证。

**DCF 假设**：
- 折现率：9%（高质量 P&C 保险的合理要求回报率）
- 预测期：5年显式 + Gordon 终值增长模型
- 现金流代理：EPS（保险公司可以将大部分利润分配给股东）

### 4.2 情景一：保守（软市场回归）

```
假设核心：
  - CR 从 86.5% 逐步回归至 95%（5年内）
  - 利率从 5%+ 下行至 3-3.5%
  - 保费增速降至 3-4%
  - 股份回购正常化至 3%/年
  - NII 从 $3.4B 降至 $2.8B

EPS 路径：
  Y1: $34  |  Y2: $32  |  Y3: $33  |  Y4: $34  |  Y5: $36
  5Y 复合增速：~2%

DCF 计算：
  PV of 5Y EPS:           $130
  Terminal Value (g=2.5%): $535
  PV of Terminal:          $348
  ─────────────────────────────
  内在价值：               $478/股

  ⚠ 注意：DCF对EPS起点敏感。如果用"正常化EPS"($25-28)作为起点，
  内在价值约 $330-370。上述结果使用了当前周期高点的EPS，请谨慎解读。

P/B 框架交叉验证：
  BVPS(Y5) ≈ $193×(1.04)^5 = $235
  公允 P/B (ROE 14%, 9% CoC) = 1.56x
  5Y 公允价格 = $235 × 1.56 = $367
  PV 公允价格 = $367 / (1.09)^5 = $238
  → 当前 $369 偏贵
```

### 4.3 情景二：中性（温和硬市场延续）

```
假设核心：
  - CR 维持在 88-91%
  - 利率缓慢下行至 4%
  - 保费增速 5-6%
  - 股份回购 4%/年
  - NII 维持 $3.3B

EPS 路径：
  Y1: $38  |  Y2: $41  |  Y3: $44  |  Y4: $47  |  Y5: $51
  5Y 复合增速：~8%

DCF 计算：
  PV of 5Y EPS:           $159
  Terminal Value (g=3.0%): $875
  PV of Terminal:          $569
  ─────────────────────────────
  内在价值：               $728/股

P/B 框架交叉验证：
  BVPS(Y5) ≈ $193×(1.08)^5 = $284
  公允 P/B (ROE 18%, 9% CoC) = 2.00x
  5Y 公允价格 = $284 × 2.00 = $568
  PV 公允价格 = $568 / (1.09)^5 = $369
  → 当前 $369 恰好公允！

  结论：在中性情景下，TRV 当前定价合理——市场给出了一个不便宜也不贵的公允价。
```

### 4.4 情景三：乐观（硬市场+回购加速）

```
假设核心：
  - CR 维持 83-86%
  - 利率维持 4.5%+
  - 保费增速 7-8%
  - 股份回购 5-6%/年
  - NII 增长至 $3.8B

EPS 路径：
  Y1: $42  |  Y2: $50  |  Y3: $58  |  Y4: $67  |  Y5: $76
  5Y 复合增速：~15%

DCF 计算：
  PV of 5Y EPS:           $202
  Terminal Value (g=3.5%): $1,386
  PV of Terminal:          $901
  ─────────────────────────────
  内在价值：               $1,103/股

P/B 框架交叉验证：
  BVPS(Y5) ≈ $193×(1.12)^5 = $340
  公允 P/B (ROE 21%, 9% CoC) = 2.33x
  5Y 公允价格 = $340 × 2.33 = $792
  PV 公允价格 = $792 / (1.09)^5 = $515
  → 当前 $369 → +40% upside

  但问题：硬市场持续到第11年（2021+10=2031），这不符合历史规律。
```

### 4.5 DCF 估值汇总

| 情景 | DCF 内在价值 | vs $369 | P/B框架5Y公允PV | vs $369 | 概率权重 |
|:---|:---:|:---:|:---:|:---:|:---:|
| 🟢 乐观 | ~$1,100 | +199% | $515 | +40% | 15% |
| 🟡 中性 | ~$728 | +97% | $369 | 0% | 50% |

> \* 保守 DCF 使用了当前高EPS为起点，实际可能高估。若使用正常化EPS ~$26，保守内在价值约 $340-370。

**核心结论**：
- DCF 在保险股上容易给出过于乐观的结果（因为起点EPS处于周期高点）
- **P/B 框架更加可靠**——概率加权预期价值约 $345，当前价格 $369 略微偏贵
- 真正的"安全边际"买点：$280-310（P/B 1.5x 附近）
